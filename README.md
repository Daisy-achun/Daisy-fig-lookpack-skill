# paper-framework-diagram

Cursor Agent Skill for drawing publication-ready computer-science paper framework / pipeline / method figures.

## Install

Copy this folder into your Cursor skills directory, e.g.:

```bash
mkdir -p ~/.cursor/skills
cp -R . ~/.cursor/skills/paper-framework-diagram
```

Or clone into `.cursor/skills/paper-framework-diagram` inside a project.

## Usage

Ask the agent to draw a paper framework / Fig.1 / method flowchart. Provide Method text and any reference figures.

## Layout

- `SKILL.md` — main instructions
- `styles/` — composition × look packs
- `references/` — icon / QA helpers
- `scripts/` — optional maintainer utilities
